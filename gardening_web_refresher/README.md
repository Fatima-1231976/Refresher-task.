# My Gardening Hobby

This project is a responsive single-page website about gardening, made with HTML5, CSS and JavaScript. The HTML uses semantic sections, headings, navigation, image alternative text and a footer. The CSS uses Grid, Flexbox and a media query so the page can adapt to smaller screens. JavaScript adds a dark/light theme switcher and a button to show or hide beginner gardening tips.

I found organising the page into sections and styling the cards straightforward. Making the layout work on a phone-sized screen and keeping the buttons accessible were more challenging. I would like to improve my JavaScript skills, especially DOM events and accessibility. Before submitting, I will test the page on phone and desktop sizes and check the browser console for errors.
